# English for Russian speakers · v1

Авторский учебный набор Voklumi. Единственный источник материалов — `english-ru.v1.json`; данные не импортируются в React и не публикуются как статические клиентские assets. Ключи ответов находятся в этом файле для редакторов и серверного импорта, а не для отправки браузеру.

30 уроков, 240 заданий, 3 курса, 7 тематических блоков:

| Курс             | Уроки | Задания | Уровень |
| ---------------- | ----: | ------: | ------- |
| Basic English    |    12 |      96 | A1      |
| Gaming English   |    10 |      80 | A2      |
| Internet English |     8 |      64 | A2      |

Каждый урок содержит цели, две заметки, мини-словарь из четырёх единиц и восемь упражнений: два выбора перевода (в обе стороны), предложение из слов, пропуск, четыре пары, грамматику, аудирование и ситуационный выбор. Все задания имеют ключ и краткое русское объяснение. Повторение слов в разных форматах намеренное: узнавание → воспроизведение → применение.

Basic English: Приветствия, Знакомство, Числа, Цвета, Семья, Повседневные действия, Простые предложения, Вопросы, Present Simple, Местоимения, Повседневное общение, Повторение.

Gaming English: Игровые команды, Командное общение, Игровые роли, Победа и поражение, Предметы, Движение, Тактика, Roblox, Dota 2, Повторение.

Internet English: Переписки, Сокращения, Интернет-выражения, Социальные сети, Мемы, Разговорный английский, Онлайн-общение, Повторение.

## Редакторские принципы

- Объяснения и инструкции — на русском; английские примеры соответствуют указанной ситуации. Явно ошибочные формы встречаются только как отвлекающие варианты, а не как образцы для заучивания.
- У выбора ответа один целевой вариант. У пропуска указан перевод; используйте лексику и конструкции урока. Допустимые варианты можно перечислять в `accepted`; движок игнорирует регистр и лишние пробелы, но не пунктуацию.
- Нейтральный английский отделён от неформального. Gonna/wanna, LOL, BRB и my bad сопровождаются оговорками о регистре. Британские и американские варианты написания не объявляются ошибками сами по себе.
- Roblox и Dota 2 описываются через общую лексику без числовых параметров патчей. Набор не является официальным материалом этих продуктов.
- Ситуационные ответы поддерживают уважительное общение и не предлагают передавать пароль или код входа. Варианты, показывающие небезопасное поведение, явно являются неверными ответами.
- Аудирование использует Web Speech API; перевод и ключ не зависят от наличия конкретного голоса. При недоступности синтеза существующий движок предлагает текстовый режим.

## Структура и изменения

`schemaVersion` описывает формат файла, `contentVersion` — редакцию материалов. Курсы и уроки имеют стабильные `slug`, упражнения — стабильные `key`. `unit` задаёт тематический блок и его позицию; `position` урока относится к этому блоку. `reference_answer` — читаемый редакторский эталон для проверки соответствия ключа варианту; в БД он не импортируется. `lexicon`, `objectives` и `notes` импортируются в отдельные поля урока, `description` и версия — в курс.

Не меняйте slug/key ради перестановки: UUIDv5 вычисляются из этих идентификаторов, а не из текста или позиции. Редактирование формулировки сохраняет ID и прогресс. Новая учебная сущность должна получить новый slug/key. Не удаляйте идентификаторы опубликованных уроков без отдельной процедуры архивирования.

## Импорт

Из корня проекта:

```bash
npm run content:check
npm run test:content
```

Первая команда только валидирует материал и показывает количество строк, ничего не записывая. Тест не требует сети, Docker или секретов.

Для Supabase сначала примените миграции, включая `202611020005_content_import.sql`. Подготовьте игнорируемый `.env.local` с `NEXT_PUBLIC_SUPABASE_URL` и **серверным** `SUPABASE_SERVICE_ROLE_KEY`:

```bash
npm run content:import
```

Импорт — одна привилегированная RPC-транзакция. Она переиспользует язык `en`, обновляет записи по стабильным UUID, проверяет задания производственным валидатором и не дублирует данные при повторном запуске. Есть транзакционная блокировка для параллельных импортов. При ошибке не публикуется частичный каталог. Клиентские роли вызывать RPC не могут.

Включённые курсы и уроки публикуются при успешном commit. Существующие попытки сохраняют свои снимки и XP. Чужие курсы и стартовый seed не удаляются. У включённых уроков удаляются лишь отсутствующие в новой редакции упражнения; прошлые снимки заданий остаются. Уроки/курсы/блоки, исключённые из файла, автоматически не удаляются и не архивируются. Для этого нужна отдельная осознанная миграция; конфликт позиций со старым блоком вызовет откат вместо скрытой потери данных.

Набор не входит в `supabase/seed.sql` автоматически: это отдельная управляемая операция. После импорта данные доступны в БД; карточки демокаталога на этом этапе не менялись. Для запуска урока используйте `/lesson?lesson=<uuid из lessons>`; стабильные ID также возвращает `importPayload` в `scripts/content/catalog.mjs`.

Набор импортирован в удалённый проект `wpctwlgfnkekgulgkxad`; подробности — в [docs/SUPABASE_DEPLOYMENT.md](../docs/SUPABASE_DEPLOYMENT.md).

## Что проверяют тесты

Автотесты проверяют количество и разнообразие заданий, все ссылки в ключах, биекцию пар, порядок слов, наличие объяснений, соответствие ключа редакторскому эталону, выбранные грамматические/лексические регрессии и распределение правильных вариантов. Каждый из 240 ответов проверяется настоящим SQL grader; завершаются все 30 уроков. Также проверяются повторный импорт, обновление и перестановка заданий, сохранность попыток, запрет клиентского импорта и атомарный откат ошибочной редакции.

Эти проверки не являются автоматическим доказательством естественности всех формулировок. При будущих редакциях дополнительно перечитывайте правильные ответы, переводы и правдоподобность отвлекающих вариантов.
