# Этап C: интерактивные упражнения

Существующий движок расширен до 20 форматов из ТЗ; прежний `grammar` сохранён как 21-й тип для совместимости. Новые форматы доступны в редакторе заданий административной панели и исполняются обычным `/lesson`. Проверка и сохранение — через прежние серверные API, снимки попыток и транзакции PostgreSQL. Новых платных API и сервисов нет.

## Форматы и контракты

Общий реестр: `src/lib/exercises/contracts.ts`. Новые авторские контракты валидируются в `authoring.ts`, затем повторно PostgreSQL-функциями. Публичные поля ниже не содержат ключей, флагов правильности и объяснений до проверки.

| Тип                  | Взаимодействие / публичные поля                       | Закрытый ключ                                                    |
| -------------------- | ----------------------------------------------------- | ---------------------------------------------------------------- |
| single_choice        | Один вариант, options                                 | value: ID                                                        |
| multiple_choice      | Несколько вариантов, options                          | value: массив минимум двух ID                                    |
| sentence             | Предложение из tokens, возможны лишние слова          | value: упорядоченные ID                                          |
| translation          | Свободный перевод, source                             | accepted: допустимые формулировки                                |
| gap                  | Пропуск в sentence                                    | accepted: допустимые ответы                                      |
| matching             | Пары left / right                                     | pairs: взаимно однозначное соответствие                          |
| word_order           | Порядок всех tokens                                   | value: упорядоченные ID                                          |
| error_identification | Найти ошибку в sentence, options                      | value: ID ошибочного фрагмента                                   |
| correction           | Исправить sentence                                    | accepted: допустимые исправления                                 |
| context_choice       | Слово по контексту sentence, options                  | value: ID                                                        |
| listening            | Озвучка text / lang и options                         | value: ID                                                        |
| dictation            | Озвучка text / lang, ввод текста                      | accepted: допустимые записи                                      |
| reading              | passage и вопрос в prompt, options                    | value: ID                                                        |
| dialogue             | Реплики lines со speaker/text, продолжение из options | value: ID                                                        |
| response_choice      | Ответ на context, options                             | value: ID                                                        |
| spelling             | Слово из tokens-букв                                  | value: упорядоченные ID                                          |
| tenses               | Время в sentence, options                             | value: ID                                                        |
| synonym_antonym      | word, relation: synonym/antonym, options              | value: ID                                                        |
| word_review          | Авторское повторение word, options                    | value: ID                                                        |
| unit_test            | 2–10 questions с ID, prompt, options                  | answers: карта ID; explanations: закрытый разбор каждого вопроса |
| grammar              | Прежний выбор конструкции из options                  | value: ID                                                        |

Вариант или токен — `{id,label}`. ID уникальны, до 64 символов; списки содержат 2–30 элементов. Открытые ответы — до 1000 символов, 1–20 авторских формулировок; тексты диктанта до 500, чтения до 5000. Контрольный блок отправляется целиком и считается одним упражнением: верен, только если верны все вопросы. После проверки показывается разбор каждого вопроса в исходном порядке. Для контрольной работы по разделу автор помещает такой блок в завершающий урок; автоматическое создание новых уроков сюда не входит.

Клиентский реестр `interactive-controls.tsx` использует переиспользуемые компоненты, прежние кнопки слов/пар/выбора и общий анимированный feedback проигрывателя. У диалогов — реплики, у чтения — текст, у открытых заданий — поле ввода, у контрольного блока — отдельные группы вопросов. Поддерживаются touch, клавиатура, уменьшение движения, состояния сохранения и ошибок. Формы администратора не требуют редактирования сырого JSON; объяснение и альтернативы хранятся в закрытом ключе.

## Серверная проверка

`lesson_answer_valid` проверяет форму пользовательского ответа, а `lesson_check_answer` — правильность с учётом снимка публичных данных и закрытого ключа. Эти операции независимы: правдоподобный, но неверный ответ сохраняется как ошибка; поддельный ID, дубли токенов и неполный контрольный объект отклоняются.

Выбор нескольких вариантов сравнивает множества, порядок выбора не влияет на оценку. Для порядка слов и букв используются последовательности **меток**, а не только ID: одинаковые буквы/слова взаимозаменяемы. Поддельные ID, повторное использование одной плитки или отсутствие нужных элементов не дают правильного результата. Прежний формат sentence сохраняет исходные правила, чтобы не менять уже сохранённые попытки.

Перевод, исправление и диктант используют несколько явно заданных допустимых формулировок. Нормализация: Unicode NFKC, регистр, пробелы, типографские апострофы, конечные `. ! ?` и фиксированный список однозначных английских сокращений (`don't` ↔ `do not`, `we're` ↔ `we are` и другие). Отрицания, порядок слов, лексический смысл и внутренние знаки не удаляются. Неоднозначные `he's`, `I'd` автоматически не раскрываются. Нет сравнения только одной исходной строки, edit-distance, семантического AI или произвольного принятия «похожих» ответов. Другие правильные переводы автор должен явно добавить в accepted; охват не равен полноценной экспертной проверке любого свободного перевода.

Для аудирования/диктанта используется прежний Web Speech API: доступные голоса устройства, кнопки прослушивания/остановки, обработка отсутствующей поддержки и ошибок, явный текстовый fallback. Это не распознавание речи и не оценка произношения. Текст для синтеза доступен браузеру по необходимости; такой режим предназначен для обучения, а не защищённого экзамена. Диктант с текстовым fallback превращается в письменную практику и не доказывает навык аудирования.

## Совместимость и защита

Миграция `interactive_exercise_types` расширяет CHECK `exercises.kind`, добавляет приватные функции проверки и сохраняет v1-проверки старых форматов. Таблицы ответов, результаты, существующие упражнения и XP не переписываются. Проверено продолжение попытки, начатой **до** миграции.

`submit_lesson_answer_core` сохраняет прежние user/attempt-lock, порядок ответов, сравнение повторного запроса, транзакционное завершение и однократное начисление наград. Меняются только валидация новых форматов, вызов проверки и дополнительный feedback контрольного блока. Внешняя обёртка доступа и Premium остаётся прежней; core по-прежнему недоступен даже service role напрямую. Повтор должен отправлять тот же JSON-ответ; изменение уже сохранённого ответа отклоняется.

Новые функции проверки закрыты для PUBLIC/anon/authenticated. Сервер использует только проверенную HttpOnly Telegram-сессию; клиент не задаёт пользователя, score или XP. Новых таблиц и копий `exercise_attempts` нет: используются `lesson_attempt_items` и `exercise_submissions`, с существующими RLS и ограничениями. Новые DTO формируются по белому списку, включая вложенные вопросы. Ключи и объяснения не попадают в запрос состояния урока; разбор возвращается только после серверной проверки отправленного упражнения.

Классификатор рекомендаций этапа B дополнен: новые грамматические задания → grammar, reading/dialogue/response → reading, listening/dictation → listening, лексические → vocabulary. Смешанный контрольный блок не выдаётся за измерение одного навыка. Это группировка типов, а не новая сертифицированная оценка CEFR.

## Контент, запуск и границы этапа

Все 32 существующих урока и 247 упражнений остаются без замены. Автор может добавлять новые типы через админ-панель; существующий серверный import RPC также использует расширенные валидаторы. Скрипт и каталог curriculum-v1 сохраняют прежний формат — расширение библиотеки и массового импорта относится к этапу D. `tests/fixtures/exercises-v2.json` — 21 локальный QA-пример с положительными/отрицательными ответами, **не** опубликованный курс и не часть клиентского bundle.

`word_review` здесь — реальный тип авторского упражнения на повторение слова. Автоматический отбор именно изученных слов, vocabulary-прогресс, SM-2 и расписание относятся к этапу E и не реализованы под видом этой кнопки. Карта и профиль не перерабатываются на этапе C.

Новые переменные окружения не нужны. После применения миграции запустить `npm run exercises:check`. Production-проверка теперь требует готовность core, placement, маршрутов и движка interactive-v2 до сборки Worker. Проверки: `npm run test:exercises`, `npm run test:unit`, `npm run test:regression`, lint/typecheck/format, Next build + Playwright; Worker build + Cloudflare dry-run + Playwright. Физический Telegram и качество голосов конкретного телефона остаются ручной проверкой.
