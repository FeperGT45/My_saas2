# Официальный тест Telegram Stars

Подготовлено 9 ноября 2026. **Официальная покупка ещё не выполнена.** Production-платежи выключены. Резервные копии отложены по явному решению владельца, платные сервисы не подключаются.

## Что подготовлено

`npm run test:stars-official` использует только официальный адрес `https://api.telegram.org/bot<TEST_TOKEN>/test/METHOD`. У него нет переключателя на production и нет произвольного API origin. Он не читает рабочий `TELEGRAM_BOT_TOKEN` или ключи Supabase. Проверяется отсутствие webhook у отдельного тестового бота; существующий webhook не удаляется.

Проверка поднимает отдельную PGlite-базу в памяти со всеми миграциями Voklumi, привязывает одного тестового пользователя одноразовой командой и отправляет два настоящих счёта Test Server: 49 тестовых Stars / 7 дней и 149 / 30 дней. Она ждёт настоящие `pre_checkout_query` и `successful_payment`, обрабатывает их существующим `processStarsUpdate` и SQL приложения, проверяет срок доступа и повтор receipt, затем вызывает официальный тестовый возврат и проверяет отзыв доступа. Результат записывается в `artifacts/stars-official-result.json` только после завершения обоих тарифов. Токены, charge ID и сырые updates не печатаются и не попадают в отчёт.

Это проверка Bot API через polling и платёжного движка Voklumi в изолированной базе. Она не подтверждает доставку production webhook, Telegram-авторизацию развёрнутого тестового Mini App или покупку через его кнопку. Эти проверки нельзя считать выполненными только по результату данного сценария.

## Вход и текущий блокер

В браузере Codex открыта отдельная вкладка `https://web.telegram.org/k/?test=1`, на экране подтверждено **Test DC**. Обычный аккаунт в Telegram Web A остаётся открытым.

Официально описанные тестовые номера DC2 и DC1 с кодами из пяти двоек/единиц были отклонены клиентом: **Invalid code**. Причина отказа не установлена; это не результат платёжного теста. Повторный перебор номеров/кодов не выполняется. Нужен рабочий вход в Test Server с отдельным аккаунтом. Можно попробовать самостоятельную регистрацию со своим номером в Test DC либо официальный способ через Telegram Desktop: Settings → Shift+Alt+правый клик Add Account → Test Server. Код пользователь вводит в Telegram самостоятельно.

Тестовые номера из публичного диапазона доступны другим разработчикам; в таких аккаунтах нельзя хранить личные данные или рабочие токены. Все сведения тестового сервера могут быть удалены Telegram.

## После входа

1. В Test DC открыть @BotFather и создать отдельного бота, например Voklumi Stars Test. Рабочий @Voklumi_bot не перенастраивать. Создание нового бота выдаёт новый токен; этот шаг выполняет владелец либо отдельно подтверждает его создание агентом.
2. Записать **только тестовый** токен в игнорируемый файл `E:/SaaS/.env.stars-test.local`: `TELEGRAM_TEST_BOT_TOKEN=...`. Не присылать его в чат. Не добавлять туда рабочие ключи или токен основного бота.
3. Запустить `npm run test:stars-official`. Если бот имеет webhook, взять нового отдельного бота; скрипт остановится, не меняя настроек.
4. В тестовом боте отправить одноразовую команду `/start stars_test_…`, показанную терминалом. Только отправитель этой команды становится участником проверки.
5. Подтвердить два счёта **в Test DC**. На основном сервере не покупать Stars для этой проверки. Между тарифами тест выполняет возврат.
6. Считать проверку пройденной только при двух PASS и итоговом JSON. При timeout или ошибке не повторять оплату вслепую: проверить тестовый бот и квитанцию. Временная база исчезает после остановки; она не является staging-хранилищем подписок.

Локальная подготовка без внешних запросов: `npm run test:stars-official -- --prepare`. Она проверяет применение схемы, но **не является официальным тестом Stars**. В текущем запуске подготовка, TypeScript, lint и существующие пять Node-тестов платежей с SQL-регрессией прошли.

Источники: [Telegram Test Environment](https://core.telegram.org/bots/features#dedicated-test-environment), [публичные тестовые аккаунты](https://core.telegram.org/api/auth#test-accounts), [Stars: Testing Payments](https://core.telegram.org/bots/payments-stars#testing-payments), [исходники переключателя Web K](https://github.com/morethanwords/tweb/blob/master/src/config/modes.ts).
