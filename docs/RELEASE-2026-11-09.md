Официальный Telegram Stars test environment и реальная покупка не проверены. Офлайн-тестовый конфиг не является Telegram test mode; транспорт пока использует production Bot API. Нельзя включать реальные платежи без отдельного разрешения владельца. Нужны отдельные test bot/account, staging Worker/Supabase и настройка транспорта по официальной документации.

В авторизованной панели Supabase → Database → Backups подтверждено: проект на **Free**, сообщение «Free Plan does not include project backups». Доступной платформенной копии нет; платный тариф не включался. Нужен защищённый ручной `db dump` с отдельно настроенным Postgres-подключением либо выбранный владельцем тариф с копиями. Ни ключ Data API, ни локальный тест восстановления не заменяют эту настройку. Восстановление/PITR production не выполнялись.

Владелец выполнил проверку на настоящем Android и сообщил: «все сохраняется и открывается» — после урока и повторного запуска сохраняются результаты, экран Premium открывается. Модель телефона и версии Android/Telegram не предоставлены; это ручной результат владельца, не автоматизированный аппаратный тест. Независимая рецензия преподавателя не выполнена и не заменяется автоматическим контролем уроков. Короткий read-only smoke/load не определяет максимальную нагрузку сервиса.
